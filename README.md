# 🍏 Rota de Ofertas - Pé de Alface (Desenvolvimento Próprio)

O **Rota de Ofertas** é o aplicativo web oficial que desenvolvi para a Pé de Alface Distribuidora, uma plataforma mobile-friendly focada em simplificar a compra de Frutas, Legumes e Verduras (FLV) para nossos clientes (restaurantes B2B e consumidores B2C).

Este repositório demonstra o desenvolvimento completo da interface e das funcionalidades cruciais de um e-commerce que tem a **Logística Otimizada** e o **Inventário de Frescor** como foco principal.

## ✨ Funcionalidades Destaque

O Web App simula um ciclo de compra e entrega, implementando lógicas importantes em JavaScript:

1.  **Catálogo Dinâmico e Ofertas:** Busca de produtos e exibição de múltiplas ofertas de preço, origem e prazo de entrega.
2.  **Gerenciamento de Carrinho:** Adição, remoção e cálculo total dos itens selecionados.
3.  **Simulação de Rastreamento (Logística):** Após a finalização do pedido, o sistema simula um processo de *checkout* e mostra uma tela de rastreamento de rota otimizada (ex: Rota 3, 4ª de 7 paradas).
4.  **Estrutura de Dados:** Utilização de objetos JavaScript (estrutura JSON) para simular o inventário e os preços da API de ofertas.
5.  **Design de Marca:** Layout limpo e moderno, alinhado com o site institucional da Pé de Alface.

## 💻 Tecnologias Utilizadas

Este projeto é um Web App puro, construído com as seguintes tecnologias de Front-end:

* **Linguagem Principal:** `JavaScript` (Utilizado para toda a lógica do carrinho, busca e simulação de rastreamento).
* **Estrutura:** `HTML5` (Definição da estrutura de conteúdo e telas).
* **Estilização:** `CSS3` (Estilização de ambas as páginas, garantindo a organização do layout).
* **Controle de Versão:** `Git` e `GitHub` (Utilizado para o versionamento do código e organização do fluxo de trabalho).
* **Bibliotecas Auxiliares:** `Font Awesome` (Ícones profissionais) e `Google Fonts` (Tipografia moderna).
